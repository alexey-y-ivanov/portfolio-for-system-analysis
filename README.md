## О репозитории

Репозиторий содержит артефакты работы системного аналитика, касающиеся **Dog Otello** — сервиса по бронированию номеров для питомцев (собак).

Артефакты:
- **dog_otello_use_case_diagram.puml** — диаграмма сценариев использования сервиса Dog Otello;
- **openapi.yaml** — спецификация OpenAPI сервиса Dog Otello;
- **create_owner_sequence_diagram.puml** — диаграмма последовательности в части создания нового пользователя сервиса Dog Otello;
- **booking_status_diagram.puml** — диаграмма состояния бронирования в сервисе Dog Otello;
- **er_diagram.puml** — фрагмент физической модели данных сервиса Dog Otello.

> ⚠️ **Примечание:** Dog Otello не является production сервисом и носит исключительно демонстрационный характер.
